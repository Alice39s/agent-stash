## @agent-stash/dsh-enhance@0.3.1

### 插件简介

插件列表里的简介改为一句话：

- /init：用其他 Coding Agent 的 /init 预设分析项目，写出 AGENTS.md
- Prompt 回溯：按 ↑↓ 翻看当前会话发过的 Prompt
- Prompt 自动补全：用所有会话的历史 Prompt 补全输入内容
- 提示词增强器：一键润色、结构化、提炼 Prompt 草稿的核心内容
- Agent Stash 基础核心框架：统一设置 Agent Stash 插件的面板、补全灰字与动画
- 消息编辑：编辑消息、重新生成回复或重试回合，改动另存为可切换的版本
- 经验提炼器：从已结束的会话里提炼可复用的流程，审核后存为 Skill

### 插件名称

插件页里显示的中文名称：

- `@agent-stash/dsh-autosuggest`：Prompt 自动补全
- `@agent-stash/dsh-enhance`：提示词增强器
- `@agent-stash/dsh-stash-kit`：Agent Stash 基础核心框架
- `@agent-stash/dsh-skill-scout`：经验提炼器，找不到发现模型和无法修改 Skill 的提示里也用这个名称

## @agent-stash/dsh-enhance@0.3.0

### 增强提示词：改写更贴近原意

- 「看看能不能」「要不要」这类调查和试探保持原来的语气，不会被改成直接动手的命令，怀疑的语气也保留；纯礼貌的客套话可以去掉。
- 会话上下文只用来弄清指代和用户仍然有效的决定。用户后来的决定取代之前的，助手提出但用户没有接受的方案不算决定，被否决的方案不会写进结果；上下文确定不了指代时保留原话。指代用户提过的要求时保留它的每一部分，例如上限和超出时的处理；指代助手的方案时只写方案本身，不带助手的理由。
- 「润色 Prompt」只在对目标有帮助时请 AI 权衡做法、风险或检查方式，写成要考虑的点，不默认追加测试、基准、回退方案和实施步骤。草稿已经写明具体做法时不追加事后检查或额外要求，只是提问时不追加修改或修复的要求。很短的草稿最多扩写到约 150 个汉字或 80 个英文单词。
- 三个预设只在有先后顺序的步骤或三项以上并列时用列表，一两个要点保留成句子，不加「请完成以下几项：」这类开场句。
- 内置指令里的示例都是完整的草稿与改写结果，包括原样返回的例子。改写结果只比草稿多了句末标点时按原稿处理，提示「已经很清楚，无需改动」。
- 草稿和上下文里写到的 `<draft_prompt>`、`<conversation_context>`、`<rewritten_prompt>` 以 `⟦tag-1⟧` 这样的占位符发给模型，结果写回输入框前换回原文。

## @agent-stash/dsh-enhance@0.2.1

### 使用 o200k_base 估算输入 Tokens

改用 tiktoken 编码器统计草稿、预设指令与关联上下文的输入文本。界面注明 o200k_base 估算，不代表所选模型的实际计费，也不包含输出 Tokens。

编码器在 DSH Host 按需创建并复用，插件卸载时释放。浏览器菜单通过防抖请求读取估算，不在输入线程加载 WASM。

## @agent-stash/dsh-enhance@0.2.0

### 增强提示词：重写内置预设，菜单显示预计用量，预设可选图标

- 内置预设的提示词按 `<role>`、`<rules>`、`<mode>` 等标签分节。「润色 Prompt」先按「仅结构化整理」的步骤整理，再在原意内补全，补写的每一句都要能追溯到草稿、会话上下文或通用的工程做法。
- 「润色 Prompt」内联 humanizer、no-ai-slop、no-negative-echo 三份写作指南（MIT），去掉改写结果里的 AI 腔。指南原样随包放在 `vendor/` 里，仓库的同步任务每天对照上游更新。自定义预设可以用 `<include ref="名称" />` 引用它们，名称不存在时改写失败并列出可用的名称。
- 菜单顶部显示本轮请求预计消耗的 token 数和关联的上下文轮数，例如「本轮润色请求将消耗大约 16,630 Tokens，已关联最近 1 轮上下文」，数字跟随指针或焦点所在的预设。估算按 DeepSeek API 文档的比例：1 个英文字符约 0.3 token，1 个中文字符约 0.6 token。
- 按钮提示改为「点我增强提示词」，关联了上下文时注明轮数。按钮的圆角与旁边的模型选择框一致。
- 预设有了图标：润色是星光，仅结构化整理是列表，更精炼是压缩图标。配置页的预设表单新增图标选择器，可从 DSH 图标库的 36 个图标里选，方向键可在网格里移动；profile 里写在预设的 `icon` 字段。
- 配置页的改写指令编辑框直接显示内置指令，可以在它的基础上修改；与内置指令相同或清空时继续使用随插件更新的版本，改过的内置预设标为「内置 · 已修改」。

## @agent-stash/dsh-enhance@0.1.0

### 新增 DSH 插件「增强提示词」

- `@agent-stash/dsh-enhance`：输入框右下角、发送按钮左侧的按钮把草稿改写成更适合交给 AI 的提示词。草稿为空时按钮不显示；菜单里有「润色 Prompt」「仅结构化整理」「使 Prompt 更精炼」三个预设，数字键 1–9 直接选择。
- 改写进行中草稿锁定，点按钮或按 Esc 停止；完成后按钮左侧出现撤销按钮，回到改写前的草稿。失败原因显示在按钮左侧，草稿不变。
- 默认使用会话的模型，并附带当前会话最近 3 轮对话的正文，按钮提示与菜单顶部显示「已关联前 N 轮上下文」。上下文不含工具调用、工具输出和推理过程，能识别出的密钥替换为 `[redacted]`；草稿里的密钥以占位符发给模型，结果写回前换回原文。
- 改写结果需要与草稿使用同一种文字、保留草稿里的代码和链接、不以回答式的开头开始，才会写回输入框。
- 在「插件」页的配置页设置模型与推理强度、超时（默认 60 秒）、附带的轮数、快捷键（默认关闭，开启后为 ⇧⌘E / Ctrl+Shift+E），以及预设的顺序、名称与改写指令，也可以添加自定义预设。
- 需要 DSH 0.2.1-rc.3 或更新的版本，在「插件」页填入 npm 包名即可安装。插件第一次启动时会从 npm 自动安装并启用 `@agent-stash/dsh-stash-kit`。
