Agent Stash is a set of Agent Skills and plugins for personal use. It adds prompt history and autocompletion to the input box of [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) (DSH) and gives Pi, DSH, Cline, Grok Build, goose and Aider the same `/init` command. It also includes style guides and skills that delegate tasks to subagents.

## Plugins

| Name                                             | Install source                  | Supported agents                         | What it does                                                                                              |
| ------------------------------------------------ | ------------------------------- | ---------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| [dsh-recall](./plugins/dsh-recall.mdx)           | `@agent-stash/dsh-recall`       | DSH                                      | Press ↑↓ in the input box to browse the prompts sent in the current session                               |
| [dsh-autosuggest](./plugins/dsh-autosuggest.mdx) | `@agent-stash/dsh-autosuggest`  | DSH                                      | Type the start of a past prompt and gray text completes the rest. Press Tab or → to fill it in            |
| [dsh-stash-kit](./plugins/dsh-stash-kit.mdx)     | `@agent-stash/dsh-stash-kit`    | DSH                                      | The panel, motion and appearance settings that the two plugins above share. They install it automatically |
| [Message edit](./plugins/dsh-message-edit.mdx)   | `@agent-stash/dsh-message-edit` | DSH                                      | Edit messages, regenerate replies or retry turns. Each change opens a new session version                 |
| [/init](./plugins/init.mdx)                      | `@agent-stash/init`             | Pi, DSH, Cline, Grok Build, goose, Aider | Analyzes the project with the `/init` prompt of another coding agent and writes `AGENTS.md`               |

## Skills

| Name                                                                | What it does                                                                |
| ------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| [`code-styleguide`](./skills.mdx#code-styleguide)                   | Google, Angular and Android Kotlin style guides, synced daily from upstream |
| [`self-use-<model>-subagent`](./skills.mdx#self-use-model-subagent) | Delegates tasks in DSH to a subagent that runs a given model                |

Install the skills with `npx -y skills add Alice39s/agent-stash`. See the [Skills](./skills.mdx#install) page for details.
