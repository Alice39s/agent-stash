Agent Stash is a set of Agent Skills and plugins for personal use. It adds prompt history, autocompletion and draft rewriting to the input box of [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) (DSH), gives Pi, DSH, Cline, Grok Build and goose the same `/init` command, and runs Aider with the same presets. It also includes style guides and skills that delegate tasks to subagents.

## Plugins

| Name                                             | Install source                  | Supported agents                         | What it does                                                                                                   |
| ------------------------------------------------ | ------------------------------- | ---------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| [dsh-recall](./plugins/dsh-recall.mdx)           | `@agent-stash/dsh-recall`       | DSH                                      | Browse the prompts sent in the current session with ↑↓                                                         |
| [dsh-autosuggest](./plugins/dsh-autosuggest.mdx) | `@agent-stash/dsh-autosuggest`  | DSH                                      | Complete the input from past prompts in every session                                                          |
| [dsh-enhance](./plugins/dsh-enhance.mdx)         | `@agent-stash/dsh-enhance`      | DSH                                      | Polish, structure, or distill a prompt draft to its core in one click                                          |
| [dsh-stash-kit](./plugins/dsh-stash-kit.mdx)     | `@agent-stash/dsh-stash-kit`    | DSH                                      | Set the panels, ghost text and motion shared by Agent Stash plugins in one place. Installed with those plugins |
| [Message edit](./plugins/dsh-message-edit.mdx)   | `@agent-stash/dsh-message-edit` | DSH                                      | Edit messages, regenerate replies or retry turns as versions you can switch between                            |
| [Skill Scout](./plugins/dsh-skill-scout.mdx)     | `@agent-stash/dsh-skill-scout`  | DSH                                      | Turn reusable workflows from finished sessions into Skills after review                                        |
| [/init](./plugins/init.mdx)                      | `@agent-stash/init`             | Pi, DSH, Cline, Grok Build, goose, Aider | Analyze the project with another coding agent's `/init` preset and write `AGENTS.md`                           |

## Skills

| Name                                                                | What it does                                                                                                      |
| ------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| [`code-styleguide`](./skills.mdx#code-styleguide)                   | Google, Angular and Android Kotlin style guides. A daily job checks upstream and opens a sync PR when they change |
| [`self-use-<model>-subagent`](./skills.mdx#self-use-model-subagent) | Delegates tasks in DSH to a subagent that runs a given model                                                      |

Install the skills with `npx -y skills add Alice39s/agent-stash`. See the [Skills](./skills.mdx#install) page for details.
