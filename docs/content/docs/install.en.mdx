The repository commits `dist/` together with the code, so installation needs no build step.

## DeepSeek Harness

We recommend importing the Agent Stash plugin market. You add the index source once, then pick the plugins you want on the Discover page. This needs DSH 0.2.1-alpha.4 or later.

### Import the Agent Stash plugin market

<Steps>
<Step>

On the Plugins page, under Experimental plugins, turn on Custom plugin market. Newer DSH versions call it Custom plugin index.

</Step>
<Step>

Switch to Discover and click Add index source.

</Step>
<Step>

Enter the URL of the Agent Stash index:

```text
https://alice39s.github.io/agent-stash/index.json
```

</Step>
<Step>

Browse the Agent Stash plugins on the Discover page and install the ones you need. [dsh-stash-kit](./plugins/dsh-stash-kit.mdx) installs automatically with dsh-recall and dsh-autosuggest, so you do not need to pick it.

</Step>
</Steps>

GitHub Actions generates the index with the DSH reference generator. The index updates after each release and on a daily schedule. It lists every released version of these npm packages. The index and these docs are published to the same GitHub Pages site.

### Install by hand

If you do not want to add the index source, or your DSH has no Discover page, install the plugins by npm package name:

<Tabs items={['Desktop app', 'Command line']}>
<Tab value="Desktop app">

<Steps>
<Step>

On the Plugins page, click Add plugin.

</Step>
<Step>

Enter an npm package name from the list below and install it:

```text
@agent-stash/init
@agent-stash/dsh-message-edit
@agent-stash/dsh-recall
@agent-stash/dsh-autosuggest
```

</Step>
</Steps>

</Tab>
<Tab value="Command line">

Add the bundles to a profile, for example `web`, which the web interface uses:

```bash
dsh plugin --profile web add @agent-stash/init
dsh plugin --profile web add @agent-stash/dsh-message-edit
dsh plugin --profile web add @agent-stash/dsh-recall
dsh plugin --profile web add @agent-stash/dsh-autosuggest
```

</Tab>
</Tabs>

GitHub Actions publishes the npm packages through npm trusted publishing, with provenance. You can also install the latest version on `main` with `github:Alice39s/agent-stash` (it contains only `/init`).

On first start, `dsh-recall` and `dsh-autosuggest` automatically install [dsh-stash-kit](./plugins/dsh-stash-kit.mdx) from npm and enable it. The three plugins need DSH 0.2.1-alpha.4 or later. DSH slash commands currently work only in the web interface and the desktop app.

## Other agents

<Tabs items={['Pi', 'Cline', 'Grok Build and goose', 'Aider']}>
<Tab value="Pi">

```bash
pi install git:github.com/Alice39s/agent-stash
```

Pi loads both the `/init` extension and the skills under `skills/`. To try it in the current session only:

```bash
pi -e git:github.com/Alice39s/agent-stash
```

</Tab>
<Tab value="Cline">

```bash
cline plugin install --git github.com/Alice39s/agent-stash
```

The plugin registers the `/init` slash command. Use it in the TUI (`cline -i`). A single run with `cline "<prompt>"` does not process slash commands.

</Tab>
<Tab value="Grok Build and goose">

Run the `agent-stash` CLI that ships with `@agent-stash/init` through `npx` to write the `/init` commands. No global install is needed:

```bash
npx -y @agent-stash/init init install grok
npx -y @agent-stash/init init install goose
```

The commands are static files and do not call the CLI when you use them. Run the install again after the upstream presets update or after you change the config.

</Tab>
<Tab value="Aider">

Run it through `npx` each time. No global install is needed:

```bash
npx -y @agent-stash/init init aider
```

For the arguments, see the Aider tab under [/init usage](./plugins/init.mdx#usage).

</Tab>
</Tabs>

## Skills

Install the skills into Claude Code, Codex, Cursor and other coding agents with the CLI from [skills.sh](https://skills.sh/Alice39s/agent-stash):

```bash
npx skills add Alice39s/agent-stash
```

For other uses, such as installing one skill only, see the [Skills](./skills.mdx#install) page.
