The skills are in the `skills/` directory of the repository. Install them with the `skills` CLI from [skills.sh](https://skills.sh/Alice39s/agent-stash), which needs Node.js 22.20 or later.

## Install

<Tabs items={['All skills', 'Pick skills', 'One skill', 'DeepSeek Harness']}>
<Tab value="All skills">

Install every skill in the repository. The command lists the coding agents it detects on your machine and writes the skills into the directories of the agents you select in the current project, where they are committed with it:

```bash
npx -y skills add Alice39s/agent-stash -s '*'
```

Add `-g` to install into `~/<agent>/skills/` in your user directory instead, so that every project can use the skills:

```bash
npx -y skills add Alice39s/agent-stash -s '*' -g
```

`-s '*'` selects every skill.

</Tab>
<Tab value="Pick skills">

```bash
npx -y skills add Alice39s/agent-stash
```

The command lists the skills in the repository and the coding agents it detects on your machine. It installs your selection into the current project. Add `-g` to install into your user directory, so that every project can use the skills.

</Tab>
<Tab value="One skill">

Append `@` and the skill name to the repository name:

```bash
npx -y skills add Alice39s/agent-stash@code-styleguide -a claude-code
```

`-a` names the agent. For the names, see the [agents that the skills CLI supports](https://github.com/vercel-labs/skills/blob/main/docs/agents.md).

</Tab>
<Tab value="DeepSeek Harness">

DSH reads `~/.agents/skills` and `.agents/skills` in the project. The skills CLI has no DSH option, but `-a codex` installs into these same directories. Add `-g` to install into your user directory:

```bash
npx -y skills add Alice39s/agent-stash -g -a codex \
  -s self-use-haiku-subagent self-use-sonnet-subagent self-use-luna-subagent self-use-dpsk-subagent
```

This command installs the four subagent skills. Remove the names after `-s` that you do not need.

</Tab>
</Tabs>

Add `--list` to list the skills in the repository without installing them. After installation, `npx -y skills update` updates the skills and `npx -y skills remove` removes them. For the other options, see the [skills CLI reference](https://www.skills.sh/docs/cli). The CLI sends anonymous install statistics by default. Set `DISABLE_TELEMETRY=1` to turn this off.

<Callout type="info" title="Pi needs no extra install">
  If you installed Agent Stash in Pi with `pi install`, Pi already loads these skills.
</Callout>

## `code-styleguide`

The included style guides. `.github/workflows/sync-code-styleguide.yml` checks upstream daily and opens a sync PR when they change:

- All guides listed in the [google/styleguide](https://github.com/google/styleguide) README (CC-BY-3.0)
- [Angular style guide](https://angular.dev/style-guide) (CC-BY-4.0)
- [Android Kotlin style guide](https://developer.android.com/kotlin/style-guide) (Apache-2.0)

## `modern-web-guidance`

The guides from [GoogleChrome/modern-web-guidance](https://github.com/GoogleChrome/modern-web-guidance), covering HTML, CSS, client-side JavaScript, forms, performance, accessibility, security and built-in AI. Each guide is one file under `references/<category>/`, and each category's `index.md` lists its guides with a one-line description, a token count and feature gates. The agent finds and reads guides locally through these indexes instead of calling the upstream `npx modern-web-guidance` CLI, so it makes no network requests and sends no usage statistics.

`.github/workflows/sync-modern-web-guidance.yml` downloads the latest `modern-web-guidance` package from npm daily, checks its integrity hash, regenerates the skill and opens a sync PR when anything changed. The indexes mark guides that rely on Origin Trial APIs or features shipped in a single engine; the agent uses them only after the user agrees or the project's `.mwgrc` turns on the matching option. The guide content is licensed under CC-BY 4.0.

## `self-use-<model>-subagent`

Four skills for dispatching subagents in DSH, one for each model:

| Skill                      | Model               | Context budget per subagent |
| -------------------------- | ------------------- | --------------------------- |
| `self-use-haiku-subagent`  | Haiku 5.5           | 100k                        |
| `self-use-sonnet-subagent` | Sonnet 5.5          | 400k                        |
| `self-use-luna-subagent`   | GPT-5.6 Luna        | 200k                        |
| `self-use-dpsk-subagent`   | DeepSeek V4.1 Flash | 200k                        |

Each skill describes the call parameters, how to estimate from the budget how much one subagent can do, how to write the prompt and how to take over after a subagent fills its context and is terminated.

## `research-writing`

20 research paper writing prompts in Chinese, one reference file each. `SKILL.md` indexes them in five groups: translation, polishing and rewriting, checking and review, figures and tables, and tools and models. When a task has a LaTeX and a Word version, pick by whether the text goes into a `.tex` file or is pasted into Word.

Sources:

- The README of [Leey21/awesome-ai-research-writing](https://github.com/Leey21/awesome-ai-research-writing), by Leey21 and MySunX
- The strict reviewer prompt from [Leey21/awesome-ai-research-writing#40](https://github.com/Leey21/awesome-ai-research-writing/issues/40), by Pioneer-wxh

The frontmatter of each reference records its original authors, the upstream link and the line range at a pinned commit. The upstream repository declares no license, and the prompt text remains the copyright of its authors.
