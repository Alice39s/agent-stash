The skills are in the `skills/` directory of the repository. Install them with the `skills` CLI from [skills.sh](https://skills.sh/Alice39s/agent-stash).

## Install

Run this in your project directory. It needs Node.js 22.20 or later:

<Tabs items={['Pick skills', 'Name a skill']}>
<Tab value="Pick skills">

```bash
npx skills add Alice39s/agent-stash
```

The command lists the skills in the repository and the coding agents it detects on your machine. It installs your selection into the current project. Add `-g` to install into your user directory, so that every project can use the skills.

</Tab>
<Tab value="Name a skill">

```bash
npx skills add Alice39s/agent-stash --skill code-styleguide -a claude-code -y
```

`--skill` names the skill, `-a` names the agent and `-y` skips the prompts.

</Tab>
</Tabs>

Add `--list` to list the skills in the repository without installing them. After installation, `npx skills update` updates the skills and `npx skills remove` removes them. For the other options, see the [skills CLI reference](https://www.skills.sh/docs/cli). The CLI sends anonymous install statistics by default. Set `DISABLE_TELEMETRY=1` to turn this off.

<Callout type="info" title="Pi needs no extra install">
  If you installed Agent Stash in Pi with `pi install`, Pi already loads these skills.
</Callout>

## `code-styleguide`

The included style guides, synced daily from upstream:

- All guides listed in the [google/styleguide](https://github.com/google/styleguide) README (CC-BY-3.0)
- [Angular style guide](https://angular.dev/style-guide) (CC-BY-4.0)
- [Android Kotlin style guide](https://developer.android.com/kotlin/style-guide) (Apache-2.0)

## `self-use-<model>-subagent`

Four skills for dispatching subagents in DSH, one for each model:

| Skill                      | Model               | Context budget per subagent |
| -------------------------- | ------------------- | --------------------------- |
| `self-use-haiku-subagent`  | Haiku 5.5           | 100k                        |
| `self-use-sonnet-subagent` | Sonnet 5.5          | 400k                        |
| `self-use-luna-subagent`   | GPT-5.6 Luna        | 200k                        |
| `self-use-dpsk-subagent`   | DeepSeek V4.1 Flash | 200k                        |

Each skill describes the call parameters, how to estimate from the budget how much one subagent can do, how to write the prompt and how to take over after a subagent fills its context and is terminated.

The four `SKILL.md` files are generated from one template. The template, the model parameters and the render script are all under `skills/self-use-haiku-subagent/scripts/`. To change the body text, edit the template under `templates/`. To change the model parameters, edit `models.yaml`. Then render the files again:

```bash
uv run skills/self-use-haiku-subagent/scripts/render.py
```
