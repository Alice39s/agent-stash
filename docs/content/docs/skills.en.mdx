The skills are in the `skills/` directory of the repository. Install them with the `skills` CLI from [skills.sh](https://skills.sh/Alice39s/agent-stash); it needs Node.js 22.20 or later.

## Install

<Tabs items={['All skills', 'Pick skills', 'One skill', 'DeepSeek Harness']}>
<Tab value="All skills">

Install every skill in the repository, targeting the coding agents detected on your machine. The skills go into the agent directories in the current project and are committed with it:

```bash
npx -y skills add Alice39s/agent-stash -s '*' -y
```

Add `-g` to install into `~/<agent>/skills/` in your user directory instead, so that every project can use the skills:

```bash
npx -y skills add Alice39s/agent-stash -s '*' -y -g
```

`-s '*' selects every skill and `-y` skips the prompts.

</Tab>
<Tab value="Pick skills">

```bash
npx -y skills add Alice39s/agent-stash
```

The command lists the skills in the repository and the coding agents it detects on your machine. It installs your selection into the current project. Add `-g` to install into your user directory, so that every project can use the skills.

</Tab>
<Tab value="One skill">

Append `@` and the skill name to the repository name:

```bash
npx -y skills add Alice39s/agent-stash@code-styleguide -a claude-code -y
```

`-a` names the agent; see the [agents that the skills CLI supports](https://github.com/vercel-labs/skills/blob/main/docs/agents.md) for the names. `-y` skips the prompts.

</Tab>
<Tab value="DeepSeek Harness">

DSH reads `~/.agents/skills` and `.agents/skills` in the project. The skills CLI has no DSH option, but `-a codex` installs into these same directories. Add `-g` to install into your user directory:

```bash
npx -y skills add Alice39s/agent-stash -g -a codex -y \
  -s self-use-haiku-subagent self-use-sonnet-subagent self-use-luna-subagent self-use-dpsk-subagent
```

This command installs the four subagent skills. Remove the names after `-s` that you do not need.

</Tab>
</Tabs>

Add `--list` to list the skills in the repository without installing them. After installation, `npx -y skills update` updates the skills and `npx -y skills remove` removes them. For the other options, see the [skills CLI reference](https://www.skills.sh/docs/cli). The CLI sends anonymous install statistics by default. Set `DISABLE_TELEMETRY=1` to turn this off.

<Callout type="info" title="Pi needs no extra install">
  If you installed Agent Stash in Pi with `pi install`, Pi already loads these skills.
</Callout>

## `code-styleguide`

The included style guides, synced daily from upstream:

- All guides listed in the [google/styleguide](https://github.com/google/styleguide) README (CC-BY-3.0)
- [Angular style guide](https://angular.dev/style-guide) (CC-BY-4.0)
- [Android Kotlin style guide](https://developer.android.com/kotlin/style-guide) (Apache-2.0)

## `self-use-<model>-subagent`

Four skills for dispatching subagents in DSH, one for each model:

| Skill                      | Model               | Context budget per subagent |
| -------------------------- | ------------------- | --------------------------- |
| `self-use-haiku-subagent`  | Haiku 5.5           | 100k                        |
| `self-use-sonnet-subagent` | Sonnet 5.5          | 400k                        |
| `self-use-luna-subagent`   | GPT-5.6 Luna        | 200k                        |
| `self-use-dpsk-subagent`   | DeepSeek V4.1 Flash | 200k                        |

Each skill describes the call parameters, how to estimate from the budget how much one subagent can do, how to write the prompt and how to take over after a subagent fills its context and is terminated.
