仓库的 `dist/` 随代码提交，安装时不需要构建。

## DeepSeek Harness

推荐导入 Agent Stash 插件市场：添加一次索引源，之后在「发现」页按需挑选要装的插件。需要 DSH 0.2.1-alpha.4 或更新的版本。

### 导入 Agent Stash 插件市场

<Steps>
<Step>

在「插件」页的「实验性插件」里打开「自定义插件市场」。较新的 DSH 叫「自定义插件索引」。

</Step>
<Step>

切到「发现」，点「添加索引源」。

</Step>
<Step>

填入 Agent Stash 的索引地址：

```text
https://alice39s.github.io/agent-stash/index.json
```

</Step>
<Step>

在「发现」页浏览 Agent Stash 的插件，选需要的安装。[dsh-stash-kit](./plugins/dsh-stash-kit.mdx) 会随 dsh-recall 与 dsh-autosuggest 自动安装，不用单独选。

</Step>
</Steps>

索引由 GitHub Actions 用 DSH 的参考生成器生成，每次发布后和每天定时更新，列出这些 npm 包的每个发布版本。它和这个文档站发布在同一个 GitHub Pages 站点上。

### 手动安装

不想添加索引源，或者所用的 DSH 没有「发现」页时，按 npm 包名手动安装：

<Tabs items={['桌面版', '命令行']}>
<Tab value="桌面版">

<Steps>
<Step>

在「插件」页点「添加插件」。

</Step>
<Step>

填入下面的 npm 包名后安装：

```text
@agent-stash/init
@agent-stash/dsh-message-edit
@agent-stash/dsh-recall
@agent-stash/dsh-autosuggest
```

</Step>
</Steps>

</Tab>
<Tab value="命令行">

把 bundle 装进某个 profile，例如 Web 界面使用的 `web`：

```bash
dsh plugin --profile web add @agent-stash/init
dsh plugin --profile web add @agent-stash/dsh-message-edit
dsh plugin --profile web add @agent-stash/dsh-recall
dsh plugin --profile web add @agent-stash/dsh-autosuggest
```

</Tab>
</Tabs>

npm 包由 GitHub Actions 经 npm trusted publishing 发布，带 provenance。也可以装 `main` 上的最新版本 `github:Alice39s/agent-stash`（只含 `/init`）。

`dsh-recall` 与 `dsh-autosuggest` 第一次启动时会从 npm 自动安装并启用 [dsh-stash-kit](./plugins/dsh-stash-kit.mdx)。三个插件都需要 DSH 0.2.1-alpha.4 或更新的版本。DSH 的斜杠命令目前只能在 Web 界面与桌面版里使用。

## 其他 Agent

<Tabs items={['Pi', 'Cline', 'Grok Build 与 goose', 'Aider']}>
<Tab value="Pi">

```bash
pi install git:github.com/Alice39s/agent-stash
```

Pi 会同时加载 `/init` 扩展与 `skills/` 下的技能。只在当前会话试用：

```bash
pi -e git:github.com/Alice39s/agent-stash
```

</Tab>
<Tab value="Cline">

```bash
cline plugin install --git github.com/Alice39s/agent-stash
```

插件注册 `/init` 斜杠命令，在 TUI（`cline -i`）里使用。`cline "<prompt>"` 单次运行时不处理斜杠命令。

</Tab>
<Tab value="Grok Build 与 goose">

用 `npx` 运行 `@agent-stash/init` 自带的 `agent-stash` 命令行，写入 `/init` 命令，不需要全局安装：

```bash
npx -y @agent-stash/init init install grok
npx -y @agent-stash/init init install goose
```

写入的是静态文件，使用时不再调用这个命令行。上游预设更新或改了配置后，重新运行一次来刷新。

</Tab>
<Tab value="Aider">

每次用 `npx` 运行，不需要全局安装：

```bash
npx -y @agent-stash/init init aider
```

参数写法见 [/init 的用法](./plugins/init.mdx#用法)里的 Aider 标签页。

</Tab>
</Tabs>

## 技能

技能用 [skills.sh](https://skills.sh/Alice39s/agent-stash) 的命令行安装到 Claude Code、Codex、Cursor 等 Coding Agent：

```bash
npx skills add Alice39s/agent-stash
```

只装其中一个技能等用法见[技能](./skills.mdx#安装)页。
