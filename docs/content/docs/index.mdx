Agent Stash 是一组自用的 Agent Skills 和插件：给 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)（DSH）的输入框加上 Prompt 历史、自动补全与草稿改写，给 Pi、DSH、Cline、Grok Build 与 goose 提供同一套 `/init` 命令，也用同样的预设驱动 Aider，另外收录风格指南和子代理委托技能。

## 插件

| 名称                                             | 安装源                          | 支持的 Agent                             | 作用                                                                |
| ------------------------------------------------ | ------------------------------- | ---------------------------------------- | ------------------------------------------------------------------- |
| [dsh-recall](./plugins/dsh-recall.mdx)           | `@agent-stash/dsh-recall`       | DSH                                      | 按 ↑↓ 翻看当前会话发过的 Prompt                                     |
| [dsh-autosuggest](./plugins/dsh-autosuggest.mdx) | `@agent-stash/dsh-autosuggest`  | DSH                                      | 用所有会话的历史 Prompt 补全输入内容                                |
| [dsh-enhance](./plugins/dsh-enhance.mdx)         | `@agent-stash/dsh-enhance`      | DSH                                      | 一键润色、结构化、提炼 Prompt 草稿的核心内容                        |
| [dsh-stash-kit](./plugins/dsh-stash-kit.mdx)     | `@agent-stash/dsh-stash-kit`    | DSH                                      | 统一设置 Agent Stash 插件的面板、补全灰字与动画，随这些插件自动安装 |
| [消息编辑](./plugins/dsh-message-edit.mdx)       | `@agent-stash/dsh-message-edit` | DSH                                      | 编辑消息、重新生成回复或重试回合，改动另存为可切换的版本            |
| [经验提炼器](./plugins/dsh-skill-scout.mdx)      | `@agent-stash/dsh-skill-scout`  | DSH                                      | 从已结束的会话里提炼可复用的流程，审核后存为 Skill                  |
| [/init](./plugins/init.mdx)                      | `@agent-stash/init`             | Pi、DSH、Cline、Grok Build、goose、Aider | 用其他 Coding Agent 的 `/init` 预设分析项目，写出 `AGENTS.md`       |

## 技能

| 名称                                                                | 作用                                                                        |
| ------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| [`code-styleguide`](./skills.mdx#code-styleguide)                   | Google、Angular 与 Android Kotlin 风格指南，每天检查上游，有更新时开同步 PR |
| [`self-use-<model>-subagent`](./skills.mdx#self-use-model-subagent) | 在 DSH 里把任务委托给指定模型的子代理                                       |

技能用 `npx -y skills add Alice39s/agent-stash` 安装，详见[技能](./skills.mdx#安装)页。
