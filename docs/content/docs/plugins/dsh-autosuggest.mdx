## 按键

| 按键                         | 作用                       |
| ---------------------------- | -------------------------- |
| <Keys keys={['Tab', '→']} /> | 填入高亮的那条             |
| <Keys keys={['↑', '↓']} />   | 有多条匹配时切换           |
| <Kbd>Esc</Kbd>               | 收起建议，改动草稿后再出现 |

点任意一行也能把它填入输入框。

## 匹配规则

- 输入的内容是某条历史 Prompt 的开头（区分大小写）时，光标后以灰字显示剩余部分，输入框上方列出最多五条匹配，标出来源会话与日期。
- 建议只在光标位于草稿末尾时出现。输入法组字、`/` 或 `@` 菜单打开、草稿里有引用块时不出现。
- 历史取自最近活跃的 50 个顶层会话（子代理会话不计入），按时间倒序，相同文本只保留最新一条，最多 500 条。
- 只有亲手输入才会出现建议，[dsh-recall](./dsh-recall.mdx) 放进输入框的内容不会触发。
- 沿着建议继续输入时灰字不重播。换成另一条建议时，灰字按 [补全灰字](./dsh-stash-kit.mdx#配置项) 的设置重新出现。

插件的 Host 半部注册只读路由 `/dsh-autosuggest/prompts`，从会话日志里取出用户亲手发送的 Prompt，经 DSH 的连接校验后返回。

## 安装

需要 DSH 0.2.1-alpha.4 或更新的版本。

<Tabs items={['插件市场', '桌面版', '命令行']}>
<Tab value="插件市场">

按[导入 Agent Stash 插件市场](../install.mdx#导入-agent-stash-插件市场)的步骤添加索引源，然后在「发现」页安装 `@agent-stash/dsh-autosuggest`。

</Tab>
<Tab value="桌面版">

在「插件」页点「添加插件」，填入 `@agent-stash/dsh-autosuggest`。

</Tab>
<Tab value="命令行">

```bash
dsh plugin --profile web add @agent-stash/dsh-autosuggest
```

</Tab>
</Tabs>

<Callout type="info" title="自动安装 dsh-stash-kit">
  和 [dsh-recall](./dsh-recall.mdx) 一样，每次启动时检查
  [dsh-stash-kit](./dsh-stash-kit.mdx)：没有安装就从 npm 安装并启用，被停用就重新启用。
</Callout>
