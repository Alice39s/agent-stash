## 用法

<Tabs items={['Pi、DSH 与 Cline', 'Grok Build 与 goose', 'Aider']}>
<Tab value="Pi、DSH 与 Cline">

三者的参数写法相同：

```text
/init                         # 使用默认预设（DSH 里先打开预设列表）
/init kimi-code               # 使用 kimi-code 预设
/init opencode 重点写测试流程   # 使用 opencode 预设并附加额外 Prompt
/init 用中文写                 # 第一个词不是预设名时，整句作为额外 Prompt，使用默认预设
```

</Tab>
<Tab value="Grok Build 与 goose">

每个预设对应一个 `/init-<预设名>` 命令，`/init` 使用默认预设。命令后面的文字都是额外 Prompt：

```text
/init                          # 使用默认预设
/init-kimi-code                # 使用 kimi-code 预设
/init-opencode 重点写测试流程    # 使用 opencode 预设并附加额外 Prompt
```

非交互运行时也能用：

```bash
grok -p "/init-opencode 重点写测试流程"
goose run -t "/init-crush 重点写测试流程"
```

</Tab>
<Tab value="Aider">

用 `npx -y @agent-stash/init init aider` 运行，不需要全局安装。它渲染预设后交给 `aider --message`，Aider 处理完这一轮就退出。参数与 `/init` 相同，`--` 之后的参数原样传给 Aider：

```bash
npx -y @agent-stash/init init aider                               # 使用默认预设
npx -y @agent-stash/init init aider opencode 重点写测试流程         # 使用 opencode 预设并附加额外 Prompt
npx -y @agent-stash/init init aider crush -- --model sonnet       # 指定 Aider 的模型
```

</Tab>
</Tabs>

### 在 DSH 里选预设

DSH 的 `/` 菜单里，`/init` 排在「指令」区，标题是「初始化」。

<Steps>
<Step>

在菜单里选「初始化」，或者只输入 `/init` 后回车，打开预设列表。

</Step>
<Step>

默认预设打勾并已高亮。输入文字可以筛选预设，自定义预设单独列在「自定义」组里。

</Step>
<Step>

按回车，用高亮的预设执行。

</Step>
</Steps>

## 额外指令与占位符

发送前去掉模板开头的 YAML frontmatter，并替换以下占位符：

- `${path}`：当前项目目录。DSH 里取会话的当前工作目录，Cline 里取工作区根目录。Grok Build 与 goose 的命令是安装时写好的文件，写成 `.`，即 Agent 运行时的当前目录。
- `{{.Config.Options.InitializeAs}}`：Crush 模板里的说明文件名，替换为 `AGENTS.md`。
- `$ARGUMENTS`：额外指令。

模板没有 `$ARGUMENTS` 时，额外指令追加到 Prompt 末尾的 `## Additional instructions from the user` 小节，没有额外指令就不加。Grok Build 的技能是静态文件，这个小节始终存在，没有额外指令时内容为空。

## 配置

| Agent                                            | 配置文件                                                                                                     |
| ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------ |
| Pi                                               | `~/.pi/agent/agent-stash/init.json`，然后是 `<项目根目录>/.pi/agent-stash/init.json`（仅在项目受信任时读取） |
| DSH                                              | `$DSH_HOME/agent-stash/init.json`（默认 `~/.dsh/agent-stash/init.json`）                                     |
| Cline                                            | `$CLINE_DIR/agent-stash/init.json`（默认 `~/.cline/agent-stash/init.json`）                                  |
| `agent-stash` 命令行（Grok Build、goose、Aider） | `$XDG_CONFIG_HOME/agent-stash/init.json`（默认 `~/.config/agent-stash/init.json`）                           |

Pi 设置了 `PI_CODING_AGENT_DIR` 时，第一个文件改为 `$PI_CODING_AGENT_DIR/agent-stash/init.json`。

```json title="init.json"
{
  "defaultPreset": "team",
  "presets": {
    "team": {
      "file": "./team-init.md",
      "description": "..."
    }
  }
}
```
