`@agent-stash/dsh-message-edit` 是一个 DeepSeek Harness 插件。每次改动都从该回合之前另开一个会话版本，原版本保持不变，随时可以切换回去。同一份构建产物支持 DSH 0.1.0-rc.3 与 DSH Desktop 0.2.1-rc.3，基于 [Moeblack/dsh-message-edit](https://github.com/Moeblack/dsh-message-edit) 0.2.3 开发。

## 使用

- 时间线视图：会话标题下方的视图标签里多出「时间线」。左侧按回合列出可编辑的消息、思考与回复，每个回合都可以重试；右侧是版本树，点击任一版本切换过去。工具栏里选择修改历史回合后，后续回合是丢弃还是按原输入重放。
- 标题栏：在上一版本与下一版本之间切换，或重新生成最后一条回复。
- 消息动作行：每条已结束的助手消息下方有编辑与重试按钮。编辑可以改本回合的用户消息，也可以改这条消息的思考或回复。

改用户消息或重试会让模型重新生成这一回合；只改助手的思考或回复不会调用模型，新版本直接采用改后的文本。

## 数据

- 新版本是一个普通的 DSH 子会话，父会话是被修改的版本，会话日志里只有 DSH 内置事件。卸载插件后，所有版本照常可以打开。
- 每个版本由哪次操作产生（编辑了哪个块、改前改后的文本）记在 DSH storage domain `message_edit` 里，时间线据此显示版本说明与撤销链。

## 安装

```bash
dsh plugin --profile web add @agent-stash/dsh-message-edit
```

桌面版在「插件」页点「添加插件」，填入 `@agent-stash/dsh-message-edit`。插件的源码与界面规则在仓库的 `packages/dsh-message-edit/` 下。
