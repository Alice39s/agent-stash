`@agent-stash/dsh-message-edit` is a DeepSeek Harness plugin. Each change opens a new session version from the point before that turn. The original version stays as it is, and you can switch back at any time. The same build supports DSH 0.1.0-rc.3 and DSH Desktop 0.2.1-rc.3. It is based on [Moeblack/dsh-message-edit](https://github.com/Moeblack/dsh-message-edit) 0.2.3.

## Usage

- Timeline view: the view tabs below the session title get a Timeline tab. The left side lists messages, reasoning and replies by turn, and turns started by a user message can be edited and retried. The right side is the version tree. Click a version to switch to it. In the toolbar, choose whether the later turns are dropped or replayed with their original input when you change an earlier turn.
- Title bar: switch between the previous and the next version, or regenerate the last turn started by a user message, from that message.
- Message actions: in turns started by a user message, each finished assistant message has Edit and Retry turn buttons below it. Edit changes the user message of that turn, or the reasoning or reply of that message. When later turns exist, the dialog lets you drop or replay them (Drop by default). Retry here drops the later turns.
- End of a turn: when a turn fails, is stopped, or ends without reply text, DSH shows no message actions for it. The plugin puts Edit message and Retry turn at the end of that turn, so you can change the message and send it again, or resend it as it is.

Changing a user message or retrying makes the model generate the turn again. Changing only the assistant's reasoning or reply does not call the model. The new version uses the edited text as it is.

## Data

- A new version is an ordinary DSH child session whose parent is the version you changed. The session log contains only built-in DSH events. After you uninstall the plugin, all versions still open as usual.
- The operation that produced each version (which block was edited, and the text before and after) is stored in the DSH storage domain `message_edit`. The timeline reads it to show version notes and the undo chain.

## Install

<Tabs items={['Plugin market', 'Desktop app', 'Command line']}>
<Tab value="Plugin market">

Add the index source as described in [Import the Agent Stash plugin market](../install.mdx#import-the-agent-stash-plugin-market), then install `@agent-stash/dsh-message-edit` from the Discover page.

</Tab>
<Tab value="Desktop app">

On the Plugins page, click Add plugin and enter `@agent-stash/dsh-message-edit`.

</Tab>
<Tab value="Command line">

```bash
dsh plugin --profile web add @agent-stash/dsh-message-edit
```

</Tab>
</Tabs>

The plugin source and its interface rules are in `packages/dsh-message-edit/` in the repository.
