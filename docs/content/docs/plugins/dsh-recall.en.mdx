## Keys

| Key                                 | Action                                                                |
| ----------------------------------- | --------------------------------------------------------------------- |
| <Kbd>↑</Kbd> (cursor at the start)  | Opens the history panel and puts the latest prompt in the input box   |
| <Keys keys={['↑', '↓']} />          | Switches between older and newer prompts                              |
| <Kbd>↓</Kbd> (on the newest prompt) | Returns to the draft from before the panel opened                     |
| <Kbd>Esc</Kbd>                      | Returns to the draft from before the panel opened                     |
| <Kbd>Tab</Kbd>                      | Keeps the current prompt and closes the panel so you can keep editing |
| <Kbd>Enter</Kbd>                    | Sends the current prompt directly                                     |

The panel groups prompts by date. You can also click any row to put it in the input box. When the `/` or `@` menu is open, the arrow keys still control the menu. When the draft contains a reference, <Kbd>↑</Kbd> does not open the panel.

While the panel is open, pressing any other key or clicking outside the input box closes the panel and keeps the current prompt. The key you pressed types as usual.

## Where the history comes from

The history contains only the prompts that you typed and sent in the current session, ordered by send time. The Host half of the plugin registers the read-only route `/dsh-recall/prompts`. The route reads these prompts from the session log and returns them after the DSH connection check. When you switch sessions, the panel switches to the history of the new session.

## Install

The plugin needs DSH 0.2.1-alpha.4 or later.

<Tabs items={['Plugin market', 'Desktop app', 'Command line']}>
<Tab value="Plugin market">

Add the index source as described in [Import the Agent Stash plugin market](../install.mdx#import-the-agent-stash-plugin-market), then install `@agent-stash/dsh-recall` from the Discover page.

</Tab>
<Tab value="Desktop app">

On the Plugins page, click Add plugin and enter `@agent-stash/dsh-recall`.

</Tab>
<Tab value="Command line">

```bash
dsh plugin --profile web add @agent-stash/dsh-recall
```

</Tab>
</Tabs>

<Callout type="info" title="dsh-stash-kit installs automatically">
  The plugin interface builds on [dsh-stash-kit](./dsh-stash-kit.mdx). Each time it starts, the
  plugin checks the kit through the plugin manager. It installs the kit from npm and enables it when
  the kit is missing, and enables it again when it is disabled. Until the kit is ready, the Plugins
  page shows Waiting for dependencies for the browser half of the plugin, and the prompt history
  route works as usual.
</Callout>

Change the frosted glass, motion, highlight, row height and key hints of the panel in one place on the [dsh-stash-kit settings page](./dsh-stash-kit.mdx#settings).
