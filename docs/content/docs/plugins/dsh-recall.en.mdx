## Keys

| Key                                 | Action                                                                |
| ----------------------------------- | --------------------------------------------------------------------- |
| <Kbd>↑</Kbd> (cursor at the start)  | Opens the history panel and puts the latest prompt in the input box   |
| <Keys keys={['↑', '↓']} />          | Switches between older and newer prompts                              |
| <Kbd>↓</Kbd> (on the newest prompt) | Returns to the draft from before the panel opened                     |
| <Kbd>Esc</Kbd>                      | Returns to the draft from before the panel opened                     |
| <Kbd>Tab</Kbd>                      | Keeps the current prompt and closes the panel so you can keep editing |
| <Kbd>Enter</Kbd>                    | Sends the current prompt directly                                     |

The panel groups prompts by date. You can also click any row to put it in the input box. When the `/` or `@` menu is open, the arrow keys still control the menu.

## Where the history comes from

The history contains only the prompts that you typed and sent in the current session, ordered by send time. The Host half of the plugin registers the read-only route `/dsh-recall/prompts`. The route reads these prompts from the session log and returns them after the DSH connection check. When you switch sessions, the panel switches to the history of the new session.

## Install

The plugin needs DSH 0.2.1-alpha.4 or later.

<Tabs items={['Desktop app', 'Command line', 'Plugin index']}>
<Tab value="Desktop app">

On the Plugins page, click Add plugin and enter `@agent-stash/dsh-recall`.

</Tab>
<Tab value="Command line">

```bash
dsh plugin --profile web add @agent-stash/dsh-recall
```

</Tab>
<Tab value="Plugin index">

Add the Agent Stash index source as described on the [Install](../install.mdx#dsh-plugin-index) page, then install `@agent-stash/dsh-recall` from the Discover page.

</Tab>
</Tabs>

<Callout type="info" title="dsh-stash-kit installs automatically">
  The plugin interface builds on [dsh-stash-kit](./dsh-stash-kit.mdx). On first start, the plugin
  installs the kit from npm through the plugin manager and enables it. If the profile already has
  the kit installed but not enabled, the plugin enables it. Until the kit is ready, the Plugins page
  shows Waiting for dependencies for the browser half of the plugin, and the prompt history route
  works as usual.
</Callout>

Change the frosted glass, motion, row height and key hints of the panel in one place on the [dsh-stash-kit settings page](./dsh-stash-kit.mdx#settings).
