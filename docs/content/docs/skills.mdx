技能在仓库的 `skills/` 目录下，用 [skills.sh](https://skills.sh/Alice39s/agent-stash) 的 `skills` 命令行安装，需要 Node.js 22.20 或更新的版本。

## 安装

<Tabs items={['安装所有技能', '选择安装', '单个技能', 'DeepSeek Harness']}>
<Tab value="安装所有技能">

一次装上仓库里的全部技能。命令列出本机检测到的 Coding Agent，选好后把技能写进当前项目里对应的 Agent 目录，随项目提交：

```bash
npx -y skills add Alice39s/agent-stash -s '*'
```

加 `-g` 装进用户目录的 `~/<agent>/skills/`，所有项目都能用：

```bash
npx -y skills add Alice39s/agent-stash -s '*' -g
```

`-s '*'` 指定全部技能。

</Tab>
<Tab value="选择安装">

```bash
npx -y skills add Alice39s/agent-stash
```

命令列出仓库里的技能和本机检测到的 Coding Agent，选好后装进当前项目。加 `-g` 则装到用户目录，所有项目都能用。

</Tab>
<Tab value="单个技能">

在仓库名后面用 `@` 接技能名：

```bash
npx -y skills add Alice39s/agent-stash@code-styleguide -a claude-code
```

`-a` 指定 Agent，可选的名字见 [skills 命令行支持的 Agent](https://github.com/vercel-labs/skills/blob/main/docs/agents.md)。

</Tab>
<Tab value="DeepSeek Harness">

DSH 读取 `~/.agents/skills` 和项目里的 `.agents/skills`。skills 命令行没有单独的 DSH 选项，`-a codex` 装到的正是这两个目录，加 `-g` 装到用户目录：

```bash
npx -y skills add Alice39s/agent-stash -g -a codex \
  -s self-use-haiku-subagent self-use-sonnet-subagent self-use-luna-subagent self-use-dpsk-subagent
```

这条命令装上四个子代理技能，按需删减 `-s` 后面的技能名。

</Tab>
</Tabs>

加 `--list` 只列出仓库里的技能，不安装。装好以后用 `npx -y skills update` 更新，`npx -y skills remove` 卸载，其余参数见 [skills 命令行文档](https://www.skills.sh/docs/cli)。命令行默认上报匿名的安装统计，设置 `DISABLE_TELEMETRY=1` 可以关闭。

<Callout type="info" title="Pi 不用再装">
  用 `pi install` 安装 Agent Stash 的 Pi 已经加载了这些技能。
</Callout>

## `code-styleguide`

收录的风格指南。`.github/workflows/sync-code-styleguide.yml` 每天检查上游，有更新时开一个同步 PR：

- [google/styleguide](https://github.com/google/styleguide) README 列出的全部指南（CC-BY-3.0）
- [Angular 风格指南](https://angular.dev/style-guide)（CC-BY-4.0）
- [Android Kotlin 风格指南](https://developer.android.com/kotlin/style-guide)（Apache-2.0）

## `self-use-<model>-subagent`

在 DSH 里派发子代理时用的四个技能，每个模型一份：

| 技能                       | 模型                | 单个子代理的上下文预算 |
| -------------------------- | ------------------- | ---------------------- |
| `self-use-haiku-subagent`  | Haiku 5.5           | 100k                   |
| `self-use-sonnet-subagent` | Sonnet 5.5          | 400k                   |
| `self-use-luna-subagent`   | GPT-5.6 Luna        | 200k                   |
| `self-use-dpsk-subagent`   | DeepSeek V4.1 Flash | 200k                   |

每个技能写了调用参数、按预算估算一个子代理能做多少、提示词怎么写，以及子代理用满上下文被终止后怎么接手。
